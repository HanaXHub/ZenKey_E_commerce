# ZenKey E-commerce Progressive Web App (PWA)

This is a **progressive web app (PWA)** version of an e-commerce website built using **HTML, CSS, JavaScript**, and **Service Workers**.  
The app supports offline caching, fast load times, and can be installed as a mobile app on supported devices.


## Features

- Fully responsive **e-commerce website**  
- **Offline support** using Service Workers and caching  
- **Installable PWA** which works like a mobile app  
- Fast load times thanks to cached assets  


## Project Structure

| Folder / File        | Description                                  |
|---------------------|----------------------------------------------|
| `index.html`        | Main landing page                            |
| `css/`              | Stylesheets                                  |
| `js/`               | JavaScript files for functionality          |
| `public/`           | Public assets (images, icons, etc.)         |
| `service-worker.js` | Handles caching and offline support         |
| `manifest.json`     | PWA configuration for installable app       |


## How to Launch

### 1. Clone the repository
```bash
git clone https://github.com/HanaXHub/ZenKey_E_commerce.git
```
### 2. Install packages
```bash
npm install
```
### 3. Start the app
```bash
cd public 
```
```bash
npm start
```
### 4. Open in browser
Navigate to http://localhost:8000
